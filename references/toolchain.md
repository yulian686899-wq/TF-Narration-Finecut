# 调用什么工具

本文件记录工具分工，由具备本地文件和命令执行能力的智能体调度现有工具。当前包内不提供独立的一键剪辑程序，格式兼容与运行环境兼容分别检查。

## 工具与职责

| 环节 | 工具 | 作用 |
|---|---|---|
| 输入检查 | ffprobe | 时长、比例、帧率、旋转信息、视频和音轨。 |
| 转写 | mlx-whisper 与已有本地 Whisper 模型 | 带时间的原声转写，供完整上下文判断和局部核对。 |
| 内容取舍 | 当前智能体、已确认规则、用户偏好和案例 | 判断重复、重录、卡壳及应保留信息。 |
| 边界辅助 | Python、NumPy 波形分析 | 辅助寻找字音、停顿及重录边界，记录切点。 |
| 剪辑执行 | FFmpeg | 同步裁切画面和原声，按选段顺序拼接。 |
| 音量处理 | FFmpeg 音频滤镜 | 平衡段落音量、统一响度及处理剪口点击声。 |
| 导出检查 | FFmpeg、ffprobe、Python | 完整解码、帧数、时长、音轨、峰值、响度和关键帧。 |
| 画面审核 | 本地网页与本地服务 | 计划支持播放、选段、循环回放和保存备注，待开发。 |

## 在实际环境调用

先查找当前环境可用的 FFmpeg、ffprobe、Python、NumPy、mlx-whisper 和本地模型；优先复用当前项目已验证的工具位置与环境。工具目录不在 PATH 时使用找到的绝对路径。不得把历史项目的脚本和文件路径直接当作本期输入。

读取媒体可用 `ffprobe -v error -show_streams -show_format -of json`。为识别提取16kHz单声道 PCM WAV；分析用音频与原始交付声音区分保存，剪辑仍从原片对应位置取声画。

在可运行 mlx-whisper 的本地 Python 环境中使用 `mlx_whisper.transcribe`，指定已有模型、中文及时间戳。专有名词提示按本期内容设置。时间戳用于定位参考，精确剪点仍需按原声核对。

已有项目的准备、识别、波形核对、渲染和验证脚本可在检查输入、输出、参数及副作用后复用；新项目按实际需要编写项目脚本。不要直接运行含有旧日期、源文件列表或输出路径的脚本。

本地工具或模型缺失时，说明具体缺口，先完成仍可进行的输入理解与规则整理。不静默换成云端识别，也不宣称已经完成转写或出片。

当前已使用的本地转写方案为 Apple Silicon 环境中的 mlx-whisper。其他系统的等价转写适配尚未验证；不要因智能体能够读取本技能就宣称其操作系统已具备完整剪辑环境。安装技能不会自动安装 FFmpeg、Python 库或语音模型。

宿主只能读取文字、没有文件或终端工具时，可以依照规则分析用户提供的转写并给出建议；无法执行的裁切与导出应说明实际缺口，不报告为已完成。平台工具名称与授权方式由当前宿主决定，技能文件不扩展工具权限。

## 操作顺序

本地转写 → 当前智能体判断 → Python 辅助定位并记录 → FFmpeg 剪辑和声音处理 → 审核 → 检查后交付。

画面和声音采用对应的同一组源区间，保持同步。每处剪切保存源文件、原片入出点、成片位置及理由，沿用项目现有记录格式即可。本版不要求额外的固定 JSON 协议或新增计划校验服务。

原片保留，渲染与返修另存版本。中间音频、转写、脚本及核对记录放项目工作目录，成片到用户指定目录。操作完成状态以真实文件和检查结果为准。

声音按[验收标准](quality-standards.md)处理并测量实际导出；不能只因设置了响度目标就报告已经达标。

## 环境边界与审核工作区

网页和本地服务的规划职责：页面播放、定位、循环试听、范围备注；服务保存标注；当前智能体读取后回原片修正，FFmpeg 出新版本。

当前尚未制作这套页面和服务。用户可先在聊天中给大致时间范围与问题，当前智能体承担精确定位。宿主支持文件、浏览器或视频预览时，可打开已有可预览文件或页面，不能把普通文件预览描述成已接通审核工作台。

保存标注与自动触发聊天继续执行是不同功能，自动唤醒需另行实现并验证。成峰 Studio 仅为后续可选适配，当前不作为可直接使用的依赖。

## 按需扩展

本期要求素材时可调用已有 `narration-asset-director`，要求图标、花字或动画时可使用 Remotion，要求封面或插画时使用图像生成能力。纯口播精剪不自动调用这些工作。配乐、音效和新配音按本期要求处理。
